# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Keep discussions technical, specific, and evidence-focused. Disagreement about implementation, measurements, compatibility, or root-cause hypotheses is welcome; harassment, threats, doxxing, or publication of another person's credentials or private data is not.

## Reporting conduct issues

- Do not post private maps, addresses, account data, logs containing secrets, or unrelated personal information as evidence.
- Use a private security-reporting path if the report itself contains sensitive material.
- Otherwise, open a minimal issue requesting a private contact path when a public discussion would expose personal data.

Maintainers may edit, hide, or remove material that exposes private data or makes technical collaboration unsafe.
